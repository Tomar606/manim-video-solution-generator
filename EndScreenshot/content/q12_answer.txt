KMnO_4 का विलयन उदासीन हो, क्षारीय हो या अम्लीय हो, प्रत्येक परिस्थिति में यह तीव्र ऑक्सीकारक का कार्य करता है।

# (1) अम्लीय माध्यम में

तनु H_2SO_4 की उपस्थिति में KMnO_4 अपचयित हो जाता है तथा इसके दो अणुओं से ऑक्सीजन के पाँच परमाणु प्राप्त होते हैं।

2KMnO_4 + 3H_2SO_4 → K_2SO_4 + 2MnSO_4 + 3H_2O + 5[O]

उदाहरण (i) फेरस लवण का फेरिक लवण में ऑक्सीकरण — अम्लीय KMnO_4 से प्राप्त नवजात ऑक्सीजन फेरस लवण को फेरिक लवण में ऑक्सीकृत करता है।

2KMnO_4 + 3H_2SO_4 → K_2SO_4 + 2MnSO_4 + 3H_2O + 5(O)

[2FeSO_4 + H_2SO_4 + (O) → Fe_2(SO_4)_3 + H_2O] × 5

2KMnO_4 + 8H_2SO_4 + 10FeSO_4 → K_2SO_4 + 2MnSO_4 + 5Fe_2(SO_4)_3 + 8H_2O

(ii) ऑक्जेलिक अम्ल का ऑक्सीकरण — अम्लीय माध्यम में KMnO_4 ऑक्जेलिक अम्ल को CO_2 में ऑक्सीकृत कर देता है।

2KMnO_4 + 3H_2SO_4 → K_2SO_4 + 2MnSO_4 + 3H_2O + 5[O]

[(COOH)_2 + (O) → 2CO_2 + H_2O] × 5

2KMnO_4 + 3H_2SO_4 + 5(COOH)_2 → K_2SO_4 + 2MnSO_4 + 8H_2O + 10CO_2

(iii) आयोडाइड आयन का आयोडीन में परिवर्तन —

2KMnO_4 + 10KI + 8H_2SO_4 → 6K_2SO_4 + 2MnSO_4 + 8H_2O + 5I_2

(iv) नाइट्राइट का नाइट्रेट में ऑक्सीकरण —

5NO_2^- + 2MnO_4^- + 6H^+ → 2Mn^2+ + 5NO_3^- + 3H_2O

# (2) क्षारीय माध्यम में

क्षारीय माध्यम में KMnO_4, MnO_2 में अपचयित होता है तथा 3 नवजात ऑक्सीजन देता है।

2KMnO_4 + 2KOH → 2K_2MnO_4 + H_2O + (O)

[K_2MnO_4 + H_2O → MnO_2 + 2KOH + (O)] × 2

उदाहरण (i) आयोडाइड का आयोडेट में ऑक्सीकरण — क्षारीय माध्यम में KI का आयोडेट में ऑक्सीकरण होता है।

2KMnO_4 + H_2O + KI → KIO_3 + 2MnO_2 + 2KOH

(ii) एथिलीन का ग्लाइकॉल में ऑक्सीकरण — क्षारीय KMnO_4 एथिलीन का एथिलीन ग्लाइकॉल में ऑक्सीकरण करता है।

CH_2=CH_2 + H_2O + (O) → CH_2OH·CH_2OH (एथिलीन ग्लाइकॉल)

# (3) उदासीन माध्यम में

उदासीन माध्यम में भी KMnO_4 ऑक्सीकारक की तरह कार्य करता है। अभिक्रिया में बना KOH विलयन को क्षारीय बना देता है। KMnO_4, MnO_2 में अपचयित हो जाता है एवं 2 मोल KMnO_4 से 3 मोल नवजात ऑक्सीजन मुक्त होते हैं।

2KMnO_4 + H_2O → 2MnO_2 + 2KOH + 3[O]

उदाहरण (i) H_2S को S में ऑक्सीकृत कर देता है।

2KMnO_4 + 4H_2S → 2MnS + S + K_2SO_4 + 4H_2O

(ii) सोडियम थायोसल्फेट को Na_2SO_4 में ऑक्सीकृत कर देता है।

8KMnO_4 + 3Na_2S_2O_3 + H_2O → 8MnO_2 + 3Na_2SO_4 + 3K_2SO_4 + 2KOH
