**4. Step order & the relation students reverse**
नियम कथन → dl चुनो → θ = 90° → dB = μ₀I dl/4πr² → dB ⊥ r (PR के अनुदिश) → घटक → व्यासतः सम्मुख अवयव → लंबवत घटक निरस्त → B = Σ dB sin φ → sin φ = a/r → Σdl = 2πa → r² = a²+x² → B.
**Commonly backwards:** with φ = ∠CPO, axial component is **dB sin φ = dB·(a/r)**, not dB cos φ. (NCERT defines θ as dB का अक्ष से कोण, इसलिए वहाँ cos θ = R/r — same thing; एक ही convention चुनकर पूरे script में रखो.) Also r³, not r², after substitution; और (a²+x²)^{3/2}.
