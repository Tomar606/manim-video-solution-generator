**1. Factual errors**

- The integrated rate law is written wrong: `t = (1/k)[A₀] − [A]`. Correct: **kt = [A₀] − [A]**, i.e. `t = ([A₀] − [A])/k`. The bracket must enclose the whole difference. The final result happens to come out right, so the error is in the line the student copies — fix it.
- OCR garbage: "अं-कायुकाल", "रान्य्यण", "आर्धी अभिक्रिया", "$B_a$", "आघालियरा", "दाल". Retype as अर्द्ध-आयुकाल, सान्द्रण, आधी अभिक्रिया, Eₐ, आरहीनियस, ढाल.
- Everything from "प्राप का ढाल क्या होगा?" onward is a **different question** (आरहीनियस समीकरण / सक्रियण ऊर्जा) spliced in by OCR. Delete it from this script — do not animate it.
- In that stray part R is taken as −4.58; R = 1.987 ≈ 2 cal K⁻¹ mol⁻¹. (Irrelevant once deleted, but don't reuse it.)
- "वह समय जिसमें आधी अभिक्रिया पूर्ण हो जाती है" is loose; keep only the सान्द्रण definition.

**2. Missing for full marks**

- State the zero-order rate law first: **दर = k[A]⁰ = k**, i.e. `−d[A]/dt = k`.
- Show the integration: `−d[A] = k dt` → integrate from [A₀] to [A], 0 to t → `[A] = [A₀] − kt`.
- State the conclusion in words plus the unit of k for zero order: **mol L⁻¹ s⁻¹**.
- Note k is constant at constant temperature, so t₁/₂ ∝ [A₀].

**3. Frozen Hindi terminology (must appear unchanged)**

शून्य कोटि की अभिक्रिया, अर्द्ध-आयुकाल (t₁/₂), प्रारम्भिक सान्द्रण [A₀], अभिकारक, वेग स्थिरांक (k), समाकलित वेग समीकरण, अभिक्रिया की दर, समानुपाती।

**4. Derivation order**

दर व्यंजक (दर = k) → `−d[A]/dt = k` → चरों का पृथक्करण → समाकलन → `[A] = [A₀] − kt` → `kt = [A₀] − [A]` → रखें t = t₁/₂, [A] = [A₀]/2 → `t₁/₂ = [A₀]/2k` → `t₁/₂ ∝ [A₀]`.

**Commonly reversed:** students write `t₁/₂ = 2k/[A₀]` or say it is *व्युत्क्रमानुपाती*. Also don't carry over first-order habit — there t₁/₂ = 0.693/k is **independent** of [A₀]. Worth one contrast line.

**5. Animation**

- Graph [A] vs t: straight line, negative slope, y-intercept [A₀], slope = −k. Mark [A₀]/2 on y-axis, drop to the line, down to t₁/₂ on x-axis.
- Second graph (optional): t₁/₂ vs [A₀] — straight line **through the origin**, slope 1/2k.
- Avoid: curved/exponential decay (that's first order), line through origin on the first graph, slope drawn as +k, and any first-order-style equal-halving marks.
