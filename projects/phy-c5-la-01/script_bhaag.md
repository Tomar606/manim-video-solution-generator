उत्तर-सार
• परिभाषाएँ: Dia—M विपरीत; χ < 0; μ_r < 1. Para—M समान; 0 < χ ≪ 1; μ_r ≈ 1 से थोड़ा अधिक. Ferro—अत्यधिक M; χ ≫ 1; μ_r ≫ 1.

• असमान क्षेत्र: Dia → कम तीव्रता; Para/Ferro → अधिक तीव्रता
• ताप: Para—χ = C/T ; Ferro—T_C के ऊपर Para ; Dia—लगभग ताप-स्वतंत्र
