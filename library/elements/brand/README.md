# Brand marks

`mpbse-seal.png`: the emblem of the Madhya Pradesh Board of Secondary Education (माध्यमिक शिक्षा मण्डल,
मध्यप्रदेश), supplied by the team on 27 Oct 2026 as a high-resolution PNG. That file had a grey checkerboard
painted into it in place of transparency, so it was cut out along its own blue ring and banner (the white
inside the ring is the emblem's own). It identifies the board whose question the reel answers; the `boardtag`
element opens every MP Board reel with it. It is the board's mark, not ours: it is used only to
name the board, never altered, never placed as if the board made or endorsed the video.
